Guía de Uso Paso a Paso

1. Control de Acceso y Rutas Protegidas (Guards)

La aplicación utiliza CanActivateFn con control estricto de roles:

  • Si no has iniciado sesión: Cualquier ruta protegida te redirigirá a /login recordando la URL de origen.
  • Si inicias como Usuario Estándar: No podrás acceder a /admin-dashboard ni a /management. El Guard redirigirá a una pantalla de acceso denegado informativa.
  • Si inicias como Administrador: Dispones de acceso irrestricto a todas las funcionalidades.
 2. Formularios Reactivos y Validación Asíncrona

En el registro (/register):

  • Validación Asíncrona de Correo: Al introducir un email, se realiza una comprobación contra el servicio con un retardo simulado de 500ms. Si introduces admin@empresa.com verás cómo se marca en rojo indicando que ya está registrado.
  • Validación de DNI/CIF: Se comprueba el formato legal español y su disponibilidad única.
 3. Consumo Dual de Datos (SQL y NoSQL)

El sistema implementa dos orígenes de persistencia concurrentes:

  • Fuente Relacional (SQL): Modela clientes y facturas relacionadas con claves foráneas, con operaciones CRUD asíncronas con Observables RxJS.
  • Fuente Documental en Tiempo Real (NoSQL): Emite flujos reactivos periódicos de auditoría y notificaciones sin recargar la página.
  • Orquestación: En el Cuadro de Mando se orquestan ambas fuentes mediante forkJoin garantizando una carga atómica.
 4. Cuadro de Mando y Exportación (PDF y CSV)

En la vista de Administrador:

  • Gráficos Interactivos: Visualización mensual de ingresos y distribución de facturas por estado con Chart.js.
  • Filtros en Vivo: Puedes filtrar por rango de tiempo (Hoy, Semana, Mes, Año) y la tabla y gráficos responderán al instante.
  • Exportación CSV: Pulsa el botón "Exportar CSV" para descargar una hoja de cálculo con codificación UTF-8.
  • Exportación PDF: Pulsa el botón "Exportar PDF" para descargar un informe corporativo con cabecera y tabla formateada usando jsPDF.
 5. Accesibilidad WCAG y Navegación por Teclado

Diseñado para cumplir con el nivel AA/AAA de WCAG 2.1:

  • Tab / Shift + Tab: Navegar secuencialmente entre tarjetas, campos y filas.
  • Enter / Espacio: Activar botones, ordenar columnas o abrir registros.
  • Etiquetas semánticas aria-label, aria-sort y roles WAI-ARIA integrados.
